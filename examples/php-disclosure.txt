Subject: [PHP-ANNOUNCE] PHP 8.3.8, 8.2.20 and 8.1.29 security releases

The PHP development team announces the immediate availability of PHP 8.3.8, 8.2.20 and 8.1.29.
These are security releases. CVE-2024-4577: argument injection when PHP runs in CGI mode on Windows
with certain code pages. Users running Apache with mod_php or php-fpm behind nginx are not affected
by the Windows-specific vector, but all supported branches received the fix. PHP 8.0 and older are
end of life and receive no fix. Exploitation in the wild has been reported.
