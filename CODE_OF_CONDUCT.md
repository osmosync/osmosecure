# Code of conduct

We want participation in this project to be respectful and harassment-free for everyone.

Expected: be kind, assume good intent, give and accept constructive feedback, and focus on the work.

Not acceptable: harassment, personal attacks, discrimination, publishing others' private information, and sustained disruption.

Maintainers may edit or remove contributions that violate this code and may restrict participation. Report concerns to the maintainer at contact@osmosync.com.

This is a short form adapted in spirit from the Contributor Covenant, version 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
